# IndoNLI

### Paper

Title: IndoNLI: A Natural Language Inference Dataset for Indonesian

Abstract: We present IndoNLI, a crowd-sourced natural language inference (NLI) dataset for Indonesian. IndoNLI covers both formal and colloquial Indonesian text to better represent the diverse language varieties in Indonesia.
